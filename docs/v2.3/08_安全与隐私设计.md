# 08 安全与隐私设计 v2

> Owner：架构师（兼安全 Owner）｜ 版本 v2.0 ｜ 安全项一票否决

---

## 1. 安全目标

1. **机密性**：会话正文、工作区文件、模型凭据绝不离开产生它的主机；令牌与 launch token 不明文落盘。
2. **完整性**：事件序不可篡改、**每主机内**单写者、`hostId` 命名空间不串、消息不重不丢。
3. **可用性**：Relay SLO 99.5%；PC 离线与手机引擎被杀是产品预期，需明确提示而非静默失败。
4. **可审计**：主机注册、配对、吊销、端点调用、引擎启停全留痕；日志不含敏感正文。

## 2. ★ 信任边界（v2 双执行点）

```
┌─ 不可信：公网 / 设备丢失 ───────────────────┐
│ 手机 App、iOS PWA、第三方客户端             │
└──────────────┬─────────────────────────────┘
   边界① 账号鉴权 + 设备令牌 + TLS（远程档案）
   边界①' ★ launch token → cookie + 回环隔离（本机档案）
┌──────────────▼─────────────────────────────┐
│ CP（账号/主机注册表/索引） ←→ Relay          │  边界② HOST_TOKEN
└──────┬──────────────────────┬──────────────┘
       │ 边界③ 令牌+白名单      │
┌──────▼────────┐      ┌──────▼──────────────────┐
│ PC 主机        │      │ ★ 手机 Termux 本机引擎   │
│ 可信执行点 A   │      │ 可信执行点 B             │
│ ~/.dsh 真源    │      │ ~/.dsh 真源（独立）      │
│ 本地文件/密钥  │      │ 本地文件/模型凭据        │
└───────────────┘      └──────────────────────────┘
```

- **CP / Relay 半可信**：只持有元数据与帧结构，拿不到会话正文与文件。
- **两台主机各自是可信执行点**，彼此不互信、不共享存储；`hostId` 是隔离边界。
- **本机引擎链路完全不经我们的服务器**（模型 API 除外），这是 v2 相对 v1 的隐私增益。

## 3. 威胁模型（STRIDE 摘要，v2 增量标 ★）

| 威胁 | 场景 | 缓解 |
|---|---|---|
| S 假冒 | 伪造 Host 注册 / 伪造手机 | HOST_TOKEN、配对码 + HMAC 挑战、`hostId` 绑定账号 |
| **★ S 假冒** | **主机被仿冒 / 中间人替换指纹** | **SSH 首次 TOFU 核对主机指纹，之后指纹变化按不匹配处理并阻断；Relay 校验同账号成员关系 + 钉住的设备公钥；移除设备即撤销凭证与在线连接**（社区借鉴 B3，见 `12` S-8.5） |
| **★ T 篡改** | **第三方窄屏适配插件 / 自定义 CSS 与官方适配叠加，覆盖官方界面或注入 DOM** | **v2.3：不写 UI、不装任何皮肤插件**；安装校验拒绝或提示冲突（TC-5.21）；CI 静态检查仓库不得出现 UI 资源目录与适配插件依赖；三档案 WebView 只加载官方 `dsh web` |
| S 假冒 | 配对码被猜中 | 6 位码 10min TTL + 5 次/分限速 + 60s 一次性挑战 |
| T 篡改 | 中继改帧、重排 seq | ≤64KiB 帧保序 + 客户端连续 seq 校验 + 全链路 TLS |
| T 篡改 | 双写撕裂日志 | **每主机内** RouteLease 单写者 + 409；静态扫描禁 `open(id,'write')` |
| **★ T 篡改** | **跨主机同名 sessionId 串数据** | **`(hostId, sessionId)` 复合主键；请求带错 hostId 即 `HOST_MISMATCH`** |
| **★ T 篡改** | **双端 DSH commit 漂移导致事件误解析** | **`dshCommit` 上报校验，不一致返回 `COMMIT_DRIFT` 且不合并索引** |
| R 抵赖 | 谁发的说不清 | `clientMsgId` + hostId + 设备指纹 + 结构化审计 |
| I 泄露 | 会话正文 / 文件上云 | 架构性保证：CP 无正文表、无文件接口；出网审计 0 字节 |
| I 泄露 | 令牌明文落盘 | 只存 `SHA-256(token)` 摘要，管理台只显示指纹 |
| **★ I 泄露** | **launch token 泄漏 → 同机其他网页访问本地引擎** | **只绑 `127.0.0.1`；覆盖 Host 头、不带 Origin；token 只在内存传给 WebView，不落日志/文件/崩溃上报** |
| **★ I 泄露** | **手机模型凭据外泄** | **凭据只存手机本地，由用户录入；不进 CP/Relay/日志；不随索引上报** |
| **★ I 泄露** | **Termux 文件系统被其他 App 读取** | **App 私有目录 + Termux 沙箱隔离；不在外部存储放会话与凭据** |
| D DoS | 重试风暴打满 Relay | 幂等去重窗口、限速、10s 防悬挂、离线立即 409 |
| **★ D 不可用** | **厂商省电策略杀引擎** | **前台服务 + 常驻通知 + 放行引导；被杀 10s 内提示；安全模式兜底** |
| **★ E 提权** | **手机插件拿到宿主全部能力** | **插件归属主机 + `allowedEndpoints` 白名单 + 工具卡只渲染 JSON 不执行代码 + 高危权限默认全关** |
| **★ E 提权** | **工具卡 JSON 注入 / 超大视图** | **≤8KiB 卡 / ≤32KiB 视图 / ≤4Hz；未知组件灰色占位；连续 5 次违规降级 web** |

## 4. 身份、配对与令牌

### 4.1 配对（远程档案）

```
PC 显式开启「允许移动端连接此设备」→ 6 位配对码（10min TTL，设备+IP 限速 5/min）
手机输码 → 一次性挑战（60s）→ HMAC-SHA256 → deviceToken
```

- 二维码仅作下载引导，不参与配对。
- 单活跃令牌；重新配对自动替换；吊销写真墓碑，重启不复活；孤儿与 30 天前吊销令牌加载时清理。

### 4.2 ★ launch token（本机档案）

```
dsh web --host 127.0.0.1 --port 3080 --no-open
 → stdout 一次性 token（每进程生成）
 → WebView 打开 http://127.0.0.1:3080/?token=… 换 cookie
 → 后续请求全带 cookie，覆盖 Host 头、不带 Origin
```

| 规则 | 说明 |
|---|---|
| 绑定 | **仅 127.0.0.1**，禁止 0.0.0.0；CI 静态扫描 |
| 生命周期 | 每进程生成，远程重启需重新配对；本机重启由 App 自动重新解析 |
| 存储 | **只在内存**，禁止写入文件、日志、SharedPreferences 持久化、崩溃上报 |
| 隔离 | 手机浏览器 / 同机其他网页无法访问；不带 Origin 防止跨站 |
| 状态 | 引擎连续两次失败 → 安全模式，不加载插件但会话保留 |

### 4.3 账号

- OAuth（Google / GitHub）主体唯一标识。
- 账号同步范围：设置、Assistant 配置、自动化定义、Memory、主机注册表。
- **账号不授予会话访问权**：能看哪些会话由 `HostProfile.accountId` + `hostId` 绑定决定；登同账号也看不到别的主机正文。

## 5. 权限模型

```yaml
allowedEndpoints:
  - 'session/*'
  - '$events/*'
```

- 默认拒绝一切其余端点；新增端点走 ADR + 白名单评审。
- 高危能力（命令执行、文件写入、读屏、点按输入、手机操控）**v2 全部默认关闭且不开放**。
- 工具卡：客户端只渲染 JSON，**不执行插件代码**；未知组件灰色占位，不允许静默丢弃。
- 手机端对 `pinned / pinnedOrder` 只读；置顶与调序只能 PC 端发起。
- 产物下载用短期临时票，过期 / 重放拒绝，不暴露主机本地绝对路径。

## 6. 数据与隐私

| 数据 | 存放位置 | 是否上云 |
|---|---|---|
| 会话事件正文 | **各自主机** `~/.dsh`（PC / 手机 Termux） | **否** |
| 工作区文件 / 产物本体 | 产生它的主机 | **否** |
| **模型凭据** | **产生它的主机本地** | **否** |
| 本地配置、launch token | 主机内存 / 本地 | **否** |
| 会话索引（标题/状态/lastSeq/workspace/hostId/dshCommit） | CP | 是（元数据） |
| 主机名、平台、能力、commit、在线状态 | CP | 是 |
| 账号设置 / Memory / 自动化定义 | CP | 是 |
| 令牌 | 仅摘要 | 摘要 |
| 产物元数据 + 下载票 | CP / Relay 临时 | 是（元数据） |

**产品层必须说清**：
- 手机查看历史消息必须连上对应在线主机；离线只能看索引与状态点。
- **切换主机不带走会话、文件、插件、定时任务**——这不是缺陷，是多真源模型的边界。
- **本机运行 ≠ 本地推理**：模型请求仍发往用户配置的提供方并计费。

**出网审计（W14）**：证明 0 字节工作区文件、0 条会话正文、0 条模型凭据、0 条 launch token 经过 CP/Relay；报告进 GA 门禁。

## 7. 传输与网络安全

- 远程全链路 TLS 1.2+；证书校验，禁止自签跳过。
- **PC 零入站端口**：主动 WSS 外连 Relay。
- **手机本机服务只绑回环**；App 内 WebView 之外的任何来源不可达。
- Relay 只做帧透传，不缓存会话内容；10s 无进度防悬挂，主机离线立即 409。
- SSH 档案的端口转发由用户自行建立，凭据只存在手机；文档提醒不要转发到 `0.0.0.0`。

## 8. 审计与可观测

**必须记录**：主机注册 / 下线、配对码生成与核销、令牌签发与吊销、**引擎启动/失败/安全模式/恢复/重置**、端点拒绝、路由冲突、`HOST_MISMATCH` / `COMMIT_DRIFT`、审批作答、产物下载票签发。

**日志字段白名单**：
```
ts, level, component, accountId, hostId, sessionId, seq, event, code, traceId
```
**禁止**：`data`（事件正文）、`deviceToken`、**launch token**、**模型凭据**、文件内容、本地绝对路径、Authorization 头、Origin。CI 正则扫描拦截。

**监控**：在线主机数、`dshCommit` 一致性、帧延迟直方图、错误码计数、补齐失败率、引擎启动失败率、保活被杀次数、出网字节数（文件通道应为 0）。

## 9. 供应链与运行时

- 双端锁 `pinned-commit.txt`，CI 校验一致；依赖锁文件入库。
- 发布走 npm provenance；Release 校验 tag 与 `package.json` 版本一致。
- **Termux 必须从 F-Droid / GitHub Releases 官方渠道安装**，不用应用商店旧版。
- **APK 签名必须固定**：签名不同无法覆盖安装，卸载会清空 Termux 环境、对话与设置。
- 交付 npm/tarball，不让用户在 Termux 里放宽 pnpm `allowBuilds` 授权。
- 插件所有注册经 `ctx.effect` 可逆；卸载后无残留路由 / 定时器 / WS / **前台服务绑定**。
- `engines.dsh` 声明支持的 DSH 版本；Node 大版本变化需重新编译原生扩展。

## 10. ★ 设备丢失与数据清除

| 场景 | 动作 |
|---|---|
| 手机丢失 | 管理台吊销该设备令牌 → 在线远程连接断开 → **本机会话无法远程清除，需提示用户自行清除 Termux 数据 / 远程擦除设备** |
| 令牌泄露 | 一键吊销全部手机会话，旧令牌立即失效 |
| launch token 疑似泄漏 | 重启本机引擎即生成新 token；旧 token 失效，无需轮换会话 |
| Relay 被入侵 | 不解析/不缓存正文，轮换 HOST_TOKEN + 全量令牌吊销；本机引擎链路不受影响 |
| 疑似日志撕裂 | 停止该主机会话写入，走 DSH resume；**禁止手工截断日志** |

> 与 v1 的差异：手机里现在有真实会话数据，**设备丢失的后果更重**，必须在首次引导与设置页明示「本机会话只在本机，丢失需自行擦除」。
