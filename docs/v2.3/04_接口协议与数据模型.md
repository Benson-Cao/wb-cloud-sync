# 04 接口协议与数据模型（PROTOCOL.md）v2

> 协议版本：`wbsync/2.3`（D-005：官方 `dsh web` 原生窄屏 UI；删除全部 UI bundle / 渲染契约字段；Carrier 抽象保留）
> Owner：架构师 ｜ 状态：重冻结
> **本文是跨组件唯一契约源**。v2 不兼容点：`SessionIndex` 主键改为 `(hostId, sessionId)`，Relay 路径 `<deviceId>` → `<hostId>`，新增 HostProfile 与工具卡契约。

## 1. 通用约定

- 传输：远程链路 HTTPS + WSS（TLS 1.2+）；**本机引擎链路为 `http://127.0.0.1:3080` 回环**，仅 App 自身可访问。
- 远程请求带 `Authorization: Bearer <deviceToken>`；本机链路用 launch token 换 cookie（见 §5.1）。
- 所有响应带 `X-Protocol-Version: wbsync/2.3`、`X-Host-Id`、`X-Dsh-Commit`。

### §1bis ★ 官方原生 UI 与 Carrier 契约（v2.3 / D-005）

**官方原生 UI**：手机界面完全由官方 `dsh web` 提供（v0.2.2-rc.1 已内置窄屏适配）。三档案 WebView 直接寻址同一官方服务：本机 `http://127.0.0.1:3080`、SSH 隧道 `http://127.0.0.1:3081`、Relay 反向代理到该 Host 的 `dsh web`。**仓库里没有 UI 源码、没有 UI 资源托管、没有 UI 版本/哈希字段**；不写移动皮肤，也不安装任何第三方窄屏适配插件（会与官方互斥）。

App 仅保留三块 **Kotlin 原生页面**：主机切换器、配对页、PC 离线页。PC 插件的 `dsh.client` 半边只做桌面设置页，不托管任何 UI 资源。

**Carrier 抽象（社区借鉴 B1）**：`client-core` 只认两个方法，三个实现（`LocalCarrier` / `SshCarrier` / `RelayCarrier`）：

```ts
interface DshCarrier {
  supportsUplink: boolean
  allowsEndpoint(endpoint: string): boolean
  call(endpoint: string, args: unknown): Promise<RpcOk | RpcError>
  openLink(opts: LinkOpts): DshMuxLink   // item / end / error 帧
                                          // cancel(streamId) / onLost
}
```

重连、generation、`watch()` 重同步全部在 `DshMux`，**与传输无关**；换 carrier 上层 `watch/prompt` 调用序列不变。能力声明下沉（B2）：被拒端点统一 `ENDPOINT_NOT_ALLOWED` / `METHOD_NOT_ALLOWED`，进 `unauthorized` 等显式重连，**禁止 App 硬编码「Relay 只支持图片」这类档案差异**。

**身份（B3）**：SSH 首次 TOFU 核对主机指纹，之后指纹变化按不匹配处理并阻断；Relay 校验同账号成员关系 + 钉住的设备公钥；移除设备即撤销凭证与在线连接。
- 时间统一 Unix 毫秒；ID 用字符串。`clientMsgId` 为 UUID v4，服务端 24h 去重窗口。
- Relay 按 ≤64KiB 帧搬运，**帧序即流序**；SSE 与 blob 不切语义边界。

### 统一响应包

```jsonc
{ "ok": true,  "data": { }, "protocol": "wbsync/2", "hostId": "..." }
{ "ok": false, "error": { "code": "HOST_OFFLINE", "message": "...", "retryable": false } }
```

### 错误码表

| code | HTTP | 含义 | 可重试 |
|---|---|---|---|
| `UNAUTHORIZED` | 401 | 令牌缺失/失效/已吊销 | 否 |
| `PAIR_CODE_INVALID` | 400 | 配对码错误/过期/超限 | 否 |
| `CHALLENGE_EXPIRED` | 400 | 挑战超过 60s | 否 |
| `ENDPOINT_NOT_ALLOWED` | 403 | 不在白名单 | 否 |
| `HOST_OFFLINE` | 409 | 目标主机未连上 | 是 |
| **`HOST_MISMATCH`** | **409** | **请求 hostId 与当前链路主机不一致** | 否 |
| **`COMMIT_DRIFT`** | **409** | **主机 DSH commit 与 pinned 不一致，拒绝索引合并** | 否 |
| `ROUTE_CONFLICT` | 409 | 该主机内会话写句柄归属冲突 | 否 |
| `SESSION_BUSY` | 409 | 单写者租约占用 | 是（退避） |
| `DUPLICATE` | 200 | `clientMsgId` 已处理 | 否 |
| `NO_PROGRESS` | 504 | 10s 无进度防悬挂 | 是 |
| `SESSION_FORMAT_UNSUPPORTED` | 422 | 日志格式本构建无法解读 | 否 |
| **`ENGINE_SAFE_MODE`** | **503** | **本机引擎处于安全模式，插件未加载** | 是（修配置后恢复） |
| ~~`RENDERER_VERSION_MISMATCH`~~ | — | **v2.3 已删除**：无自研渲染器与协议渲染契约 | — |
| ~~`UI_BUNDLE_MISMATCH`~~ | — | **v2.3 已删除**：无 UI bundle 与双投放 | — |
| `UNKNOWN_EVENT_IGNORED` | — | 客户端跳过 `ignorable` 未知事件 | — |

## 2. 数据模型（CP / Postgres）

```sql
Account {
  accountId, provider, subject, settings, memoryRef, automations, createdAt
}

-- ★ v2：主机注册表（取代 v1 纯 Device 表）
HostProfile {
  hostId         text PK,        -- 全局唯一、稳定
  accountId      text FK,
  kind           text,           -- 'on-device' | 'ssh' | 'relay'
  deviceName     text,           -- 取「关于本机」；手机取机型
  platform       text,           -- 'android' | 'windows' | 'macos' | 'linux' | 'ios-pwa'
  dshCommit      text,           -- 必须与 pinned-commit.txt 一致
  capabilities   jsonb,          -- ['slots','tool-cards','attachments','artifacts','schedule','approval','native-ui']
  allowMobile    boolean,
  state          text,           -- 'online' | 'offline' | 'safe-mode'
  lastSeenAt     bigint,         -- 心跳 15s，>45s 判离线
  tokenDigest    text,           -- SHA-256(deviceToken)，仅远程档案
  tombstone      boolean
}

-- ★ 主键改为 (hostId, sessionId)
SessionIndex {
  hostId         text,
  sessionId      text,
  accountId      text,
  workspace      text,           -- SessionHeader.cwd
  title          text,
  pinned         boolean,
  pinnedOrder    int,
  state          text,           -- 'running'|'awaiting'|'completed'|'unreadable'
  lastSeq        bigint,
  lastActiveAt   bigint,
  headerRef      jsonb,
  PRIMARY KEY (hostId, sessionId)
}

RouteLease {                    -- ★ 作用域缩到主机内
  hostId, sessionId, leaseId, expiresAt,
  PRIMARY KEY (hostId, sessionId)
}

Cursor {
  clientId, hostId, sessionId, sinceSeq, updatedAt,
  PRIMARY KEY (clientId, hostId, sessionId)
}

Idempotency {
  hostId, clientMsgId, result, createdAt,
  PRIMARY KEY (hostId, clientMsgId)   -- ★ 幂等键也带 hostId
}
```

> `SessionHeader`：`version / id / createdAt / cwd / parentSession / isSeeded / origin / delegationDepth / agentPreset`。跨主机展示工作空间与谱系以它为准，不要自己猜标题或层级。

## 3. DSH 事件契约（透传，不改字段）

```ts
type SessionEvent = {
  type: string
  seq: number        // 会话内连续无间隙，= log.length
  time: number
  data: unknown
  ignorable?: true
}
```

| 类别 | 事件 | 客户端处理 |
|---|---|---|
| **Surface** | `system/message`、`user/message`、`assistant/message`、`tool/result` | 渲染为对话消息 |
| 流式 | `assistant/chunk` | 折叠成 `assistant/message` |
| 轮次/步骤 | `turn/*`、`step/*` | 过程条、状态点 |
| 工具 | `tool/call` / `tool/result` | 按 `callId` 配对 |
| 仅日志 | `request/header`、`todo/write`、`hook/*`、`session/end-seed` | 不进消息流 |
| 压缩 | `compaction/*` | 遮蔽旧节点，**日志原文不变，禁止回写** |
| **★ 工具卡** | 自定义 `wbsync/card` 或插件声明的卡片事件 | 按 JSON 视图渲染，**不执行插件代码** |
| 恢复 | `turn/end { reason: { kind: 'interrupted' } }` | 由 DSH resume 合成 |

`turn/end` 原因：`completed / aborted / blockaded / error / max-tokens / interrupted`。

## 4. ★ 工具卡契约（跨主机 UI 唯一通道）

```jsonc
// 随 SessionEvent 下发，落进日志
{
  "t": "wbsync/card",
  "cardId": "artifact:report-001",
  "kind": "artifact | approval | metric | table",
  "view": { /* JSON 视图，插件只给数据不写代码 */ },
  "actions": [ { "id": "allow", "label": "允许" }, { "id": "deny", "label": "拒绝" } ]
}
```

| 限额 | 值 |
|---|---|
| 面板视图 | ≤ 32 KiB |
| 单张工具卡 | ≤ 8 KiB |
| 数据合并频率 | ≤ 4 Hz |
| 效果窗口 | 3s |

**规则**：
- 工具卡随对话记录下发，**任何主机、任何客户端都能渲染**，无需桥接。
- 客户端只渲染 JSON，用自带组件；未知组件显示灰色占位，不允许静默丢弃。
- 原生插槽（胶囊 / 消息菜单 / 状态条 / 面板）**仅本机引擎可用**；远程档案下降级为工具卡或 web island。
- 清单校验失败只丢弃该条目，并在插件详情标注问题数；连续 5 次违规整体降级为 web 版本，重启引擎或重新启用后恢复。

## 4.1 事件分类（v2.3 改写：供插件与索引使用，**非协议级渲染契约**）

> **D-005 后界面由官方 `dsh web` 渲染，我们不再规定任何渲染规则**。下表仅用于 PC 插件做事件透传分类、CP 推导状态点、以及协议内置卡片的校验；`renderContract` / `rendererVersion` / Golden Fixture 全部删除。

| 规则 | 规定 |
|---|---|
| Surface 投影 | 仅 `system/message`、`user/message`、`assistant/message`、`tool/result` 产生消息 |
| 结构事件 | `turn/*`、`step/*`、`request/*`、`todo/*`、`hook/*`、`session/end-seed` 不进消息流 |
| 流式折叠 | `assistant/chunk` 按 `sourceEventSeqs` 折叠为对应 `assistant/message`；未完成时不单独刷屏 |
| 工具配对 | `tool/call` 与 `tool/result` 按 `callId` 配对 |
| 压缩 | `compaction/start→summary→end` 遮蔽旧节点，**视图缩短、日志原文不变、禁止回写** |
| 顺序 | 严格按会话内连续 `seq`；缺口未补齐时等待，不猜测、不补写 |
| 未知事件 | `ignorable: true` 跳过；无标记的未知类型进诊断日志但不中断渲染 |
| 状态点 | 四态由 `turn/start` / `$events` 待答 / `turn/end` / 读取失败推导 |
| 卡片 | `wbsync/card` 的 `kind` 为**封闭枚举**：`artifact / approval / metric / table`；未知 kind 灰色占位，不降级 |

**卡片 `kind` 变更**：新增 `kind` 必须升卡片 schema 并走协议变更流程（客户端未知 kind 灰色占位）；**不再需要**升 `renderContract` 或维护视图快照。

**版本一致性**：唯一约束是双端 `pinned-commit.txt`（v0.2.2-rc.1 对应 commit），漂移即 `COMMIT_DRIFT`；官方 UI 的窄屏行为随该版本固定，升级走独立 ADR。

## 5. 三条链路的连接契约

### 5.1 ★ 本机引擎（on-device）

```
1. App 前台服务拉起 Termux：
   dsh web --host 127.0.0.1 --port 3080 --no-open
2. stdout 解析一次性 launch token
3. WebView 打开 http://127.0.0.1:3080/?token=… 换 cookie
4. 后续 HTTP/WS 全带 cookie；覆盖 Host 头、不带 Origin
5. 服务只绑回环 → 手机浏览器 / 同机其他网页无法访问
```

- 引擎状态机：`starting → running | safe-mode | failed`。
- 连续两次启动失败 → `safe-mode`（不加载插件，会话保留）；恢复后重新加载。
- `lib/` 代码变更需重启引擎；`package.json` 清单变更按 mtime 重读；移除并重加不会重载已加载代码。
- 本机插件安装：`dsh plugin --profile web add /absolute/path/to/plugin`（链接目录，勿删）。`engines.dsh` 声明支持的 DSH 版本。

### 5.2 SSH 档案

```
ssh -L 3081:127.0.0.1:3080 user@remote-host
地址填 http://127.0.0.1:3081，贴入远程 dsh web 打印的 token
cookie 默认 30 天；远程进程重启 token 变化，需重新配对
```

### 5.3 Relay 档案

```
POST /pair        6 位码(10min TTL, 5次/分限速) → challenge(60s)
POST /pair/verify HMAC-SHA256 响应 → deviceToken
WS   /ws/host     PC 主动注册 + host/sessions 全量索引 + 15s 心跳
ANY  /d/<hostId>/session/*   HTTP 反向代理
WS   /d/<hostId>/events/*    事件流帧透传
ANY  /d/<hostId>/$events/*   审批 / 提问通道
GET  /manifest.webmanifest   无鉴权静态（PWA 必需）
```

配对码仅作一次性信任建立；二维码仅作下载引导，不参与配对。单活跃令牌、摘要落盘、吊销写墓碑。

## 6. 主机切换协议

```jsonc
// 客户端 → CP
POST /api/hosts/select { "hostId": "...", "confirmNoMigration": true }

// CP → 客户端
{ "hostId", "kind", "dshCommit", "endpoint", "capabilities",
  "notice": "切换主机不会带走会话、文件与插件" }
```

- 客户端收到后**清空当前会话视图**，按新 `hostId` 拉 `SessionIndex`，重建链路。
- 任何携带旧 `hostId` 的后续请求返回 `HOST_MISMATCH`。
- `dshCommit` 与 `pinned-commit.txt` 不一致时返回 `COMMIT_DRIFT`，索引不合并、只提示升级。

## 7. CP REST

```
GET  /api/me
GET  /api/me/hosts                     HostProfile[]（含 kind / state / dshCommit / 状态点）
GET  /api/sessions?hostId=&pinned=     SessionIndex[]
POST /api/sessions                     在指定在线主机新建会话/工作空间
PATCH /api/sessions/:hostId/:id        置顶 / 调序（仅 PC 端可写）
DELETE /api/sessions/:hostId/:id       移除工作空间
POST /api/hosts/:id/revoke             吊销令牌 + 断开在线客户端
GET  /api/artifacts?hostId=&sessionId= 产物元数据 + 临时下载票
```

**CP 不提供任何「读取消息正文」接口。** 手机查看历史必须连上对应在线主机。

## 8. Host 本地具名路由（`ctx.webServer`）

| kind | path | 用途 |
|---|---|---|
| exact | `/__wbsync/pair` | 生成/展示配对码（远程档案） |
| exact | `/__wbsync/status` | 连接状态、hostId、dshCommit、引擎状态 |
| exact | `/__wbsync/config` | relayUrl / hostToken / autoConnect |
| prefix | `/__wbsync/static/` | client 半边与工具卡静态资源 |
| exact | `/__wbsync/artifacts/:id` | 产物临时下载票换流 |

- `register()` 返回 disposer，**必须**交 `ctx.effect()`。
- 重复注册同 kind+path 抛异常；回退席位全局唯一，本项目不注册。
- **v2.3：插件不托管任何 UI 静态资源**。手机 WebView 直接打开官方 `dsh web`（Relay / SSH 只做 HTTP·WS 反代），PC 的 `dsh.client` 半边仅提供桌面设置页。
- PC 离线时 App 显示 Kotlin 原生离线页（设备列表 + 状态点 + 明确提示），不加载任何 Web UI。

```yaml

  - 'session/*'
  - '$events/*'
```

## 11. 版本与兼容

- `wbsync/1 → 2` 为不兼容升级（hostId 命名空间）。Relay 同时兼容 1/2 至少 90 天。
- 新增事件类型带 `ignorable: true`；新增字段可选 + 默认值；删除字段走 90 天弃用期。
- 字段类型以锁定 DSH commit 为准；升级 DSH 前跑双端全量契约测试。
- **v2.3：基线锁 `v0.2.2-rc.1` 对应 commit**。该版本为 rc，官方明示行为仍在收敛；升级单开 ADR + 官方窄屏冒烟 + 全量 E2E，不在迭代中途进行。
