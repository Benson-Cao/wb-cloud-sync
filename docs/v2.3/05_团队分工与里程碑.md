## 4. 协作流程

- 分支：`main` 受保护；`feat/<模块>-<简述>`；协议变更 `proto/*` 必须 ARC Review；**Termux / Android 相关 PR 需附真机截图或录屏**。
- DoD：代码合入 + 单测 + 协议文档同步 + E2E + CHANGELOG + Review；双端 commit 校验通过。
- 会议：每日站会 15min；协议同步会周一次；周会 30min；里程碑评审 M1–M4；ADR 按需。
- 决策不留群里：结论回写 ADR 或协议文档，否则视为未决策；阻塞 > 4h 升级 PM。
- **主机模型争议**（是否迁移会话、是否加第四档案）一律上报发起人。
