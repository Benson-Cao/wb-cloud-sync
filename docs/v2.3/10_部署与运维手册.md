# 10 部署与运维手册 v2

> Owner：BE-RL（兼 SRE）｜ 版本 v2.0 ｜ 面向：自托管用户、运维、值班、Android 用户

## 1. 部署拓扑

| 组件 | 建议规格 | 端口 | 说明 |
|---|---|---|---|
| Relay | 2C4G（WS 长连，内存敏感） | 443 | 仅 `relay` 档案需要 |
| CP + Postgres | 2C4G | 443 / 内网 5432 | 仅元数据 |
| PC 主机 | 用户自有 | **无入站** | 主动 WSS 外连 |
| **Termux 本机引擎** | **用户 Android 手机** | **127.0.0.1:3080（回环）** | 外部不可达 |
| Android App | 手机 | — | WebView + 前台服务 |
| iOS PWA | 静态托管 | 443 | 仅 `ssh` / `relay` 档案 |

> **本机引擎链路完全不需要我们的服务器**：只用 Termux + 用户自己的模型提供方。只用远程功能才需要部署 Relay/CP。

| 端 | 要求 |
|---|---|

## 3. 云侧一键部署（自托管）

```bash
git clone <repo> && cd wb-cloud-sync/deploy
cp .env.example .env
# CP_OAUTH_GOOGLE_ID / SECRET, CP_OAUTH_GITHUB_ID / SECRET
# RELAY_HOST_TOKEN=<高强度随机>   ADMIN_TOKEN=<高强度随机>
# POSTGRES_PASSWORD / PUBLIC_BASE_URL
docker compose up -d
docker compose logs -f relay control-plane
```

```bash
curl -s https://cp.example.com/healthz
curl -s https://relay.example.com/manifest.webmanifest   # 必须无鉴权
```

> `/manifest.webmanifest` 必须无鉴权静态提供：浏览器拉 manifest 不带 cookie，走不了代理，否则 PWA 装不上。

## 4. ★ Android / Termux 安装（v2 新增）

### 4.1 用户首次启动引导

```
1. 安装 Termux（F-Droid / GitHub Releases，不用应用商店旧版）
2. 授权 App 前台服务与通知权限
3. 引导页执行：
     pkg update && pkg upgrade
     pkg install nodejs git
4. App 安装与 pinned-commit.txt 一致的 DSH，校验 engines.dsh
5. 录入模型提供方 Base URL / API Key（只存本机）
6. 点「启动本机引擎」
```

> **本机运行 ≠ 本地推理**：模型请求发往用户配置的提供方，需联网并按其账号计费。

### 4.2 引擎启动链路

```
前台服务 → dsh web --host 127.0.0.1 --port 3080 --no-open
 → stdout 解析一次性 launch token
 → WebView 打开 http://127.0.0.1:3080/?token=… 换 cookie
 → 后续请求全带 cookie（覆盖 Host 头、不带 Origin）
 → 状态 = 运行中
```

- **只绑回环**，禁止 `0.0.0.0`；手机浏览器与同机其他网页不可达。
- 连续两次启动失败 → **安全模式**（不加载插件，会话保留）→ 修配置后点「恢复正常模式」。
- 首次约 1GB 落盘、冷启动几秒（Node 加载插件），引导页给进度。
- **引擎重置会清空本机会话 / 工作区 / 插件 / 设置，不可撤销** → 二次确认 + 先导出提示。

### 4.3 保活设置

- 打开前台服务 + 常驻通知；关闭电池优化；最近任务锁定 App。
- 被系统杀掉后 App 10s 内提示，并直达对应品牌放行设置：vivo / 小米 / 华为 / 荣耀 / OPPO。
- **"直达设置" ≠ "一定能放行"**；低配机或长任务建议切到远程主机档案。
- 发热、耗电、存储占用在使用前与长任务时明示。

### 4.4 ★ 手机侧不装插件；界面 = 官方 `dsh web`（v2.3 / D-005）

**Termux 只安装原版 DSH（锁 `v0.2.2-rc.1` 对应 commit），不安装 `dsh-wb-cloud-sync`，也不需要任何手机插件目录。**

```bash
# 仅此即可，无 dsh plugin add 步骤
npx @deepseek-ai/dsh web --host 127.0.0.1 --port 3080 --no-open
```

- **官方 `dsh web` 已原生适配窄屏**（软键盘、抽屉、设置页、安全区、宽表格），我们**不写 UI、不写皮肤、不托管 UI 资源**。
- 三档案 WebView 直接寻址同一个官方服务：本机 `:3080` / SSH 隧道 `:3081` / Relay HTTP·WS 反代到该 Host 的 `dsh web`。**切档案后界面天然一致**，无版本或哈希需要校验。
- **不要安装第三方窄屏适配插件**（`dsh-client-ui-mobile` / `dsh-pocket-ui` / `dsh-mobile` 等）：与官方适配互斥，会互相覆盖。
- App 内只内置 `client-core`（`DshCarrier`×3 + `DshMux`），服务 App 壳；手机侧无插件管理页、无 slots / 清单校验器、无 UI 源码。
- 产物与审批以**协议内置卡片**下发，`kind` 为封闭枚举，由官方 UI 侧组件渲染、**不执行插件代码**。
- **PC 离线时** App 显示 Kotlin 原生离线页（设备列表 + 状态点 + 明确提示），不能白屏。
- **唯一插件在 PC 侧**：`dsh plugin --profile web add dsh-wb-cloud-sync`（见 §5）；其 `dsh.client` 半边只做桌面设置页。
- **上游升级时只改插件与 `pinned-commit`**，APK 里没有 UI 需要跟；该 rc 版本行为仍在收敛，升级单开 ADR + 官方窄屏冒烟。

### 4.5 分发与升级

- **APK 侧载，签名必须固定**：签名不同无法覆盖安装，卸载会清空 Termux 环境、对话与设置。
- 普通引擎更新只替换 App 管理的组件，保留工作区与配置；**Node 大版本变化需重编译原生扩展**。
- 不上 Google Play；Termux 由用户自行从官方渠道安装。

## 5. PC 主机插件

```bash
dsh plugin --profile web add dsh-wb-cloud-sync
# 或 dsh plugin --profile web add ./dsh-wb-cloud-sync-0.2.0.tgz
# 完全退出桌面版后执行，重启即生效
```

设置 → 「手机连接」：

| 配置 | 说明 |
|---|---|
| 中继地址 | `https://relay.example.com` |
| HOST_TOKEN | 与 Relay 一致 |
| 启动时自动连接 | 默认开 |
| 允许移动端连接此设备 | 必须显式开启 |

验证：

```bash
dsh --profile web --dump-config | grep wb-cloud-sync
curl -s http://127.0.0.1:3080/__wbsync/status   # 含 hostId / dshCommit / 引擎状态
```

> 交付 npm/tarball，避免用户处理 pnpm `allowBuilds` 授权；client 半边元数据有缓存，首次安装后重启一次 DSH。

## 6. 手机端接入（三档案）

| 档案 | 操作 | 依赖 |
|---|---|---|
| **本机引擎** | 引导装 Termux → 启动引擎 → 自动进入 | 无需账号、无需我们的服务器 |
| **SSH** | `ssh -L 3081:127.0.0.1:3080 user@pc` → 地址填 `http://127.0.0.1:3081` → 贴入远程 `dsh web` 打印的 token | 同一网络 / 可达 SSH；cookie 默认 30 天，远程重启需重新配对 |
| **Relay** | 同 OAuth 账号登录 → PC 生成 6 位配对码（10min）→ 手机输码 → 自动挑战响应 → 选设备 | Relay + CP |

> 二维码仅作下载引导，**不参与配对**。设备关系持久保留，一次配对永久有效；重新配对替换旧令牌。

**切换主机时必现提示**：「切换主机不会带走会话、文件与插件」。顶部常驻当前执行位置。

## 7. 日常运维

### 监控指标

| 指标 | 告警阈值 |
|---|---|
| 在线主机数 | 突降 >50% |
| `dshCommit` 与 pinned 不一致 | **>0 即告警** |
| 帧延迟 P95 | 跨网 >800ms 持续 5min |
| `HOST_OFFLINE` / `HOST_MISMATCH` 占比 | >20% / 突增 |
| `ENDPOINT_NOT_ALLOWED` 计数 | 突增 |
| `NO_PROGRESS` | >10/min |
| 补齐失败率 | >0 |
| **引擎启动失败率 / 被杀次数** | 突增 |
| 文件通道出网字节 | **>0 即告警** |

### 日志

字段：`ts, level, component, accountId, hostId, sessionId, seq, event, code, traceId`。
**禁止**打印事件 `data`、deviceToken、**launch token**、**模型凭据**、文件内容、本地绝对路径；CI 正则扫描。

### 管理台

`https://relay.example.com/admin`（`--admin-token`）：设备/主机总览（全部/在线/离线）、配对码有效期、令牌指纹、断开手机 / 吊销 / 删除（真墓碑）、单活跃令牌状态、孤儿与 30 天前吊销令牌自动清理。

## 8. 故障排查（v2 增补标 ★）

| 现象 | 可能原因 | 处置 |
|---|---|---|
| ★ 本机引擎起不来 | Termux 未装 / nodejs 版本不符 / DSH 版本与 pinned 不一致 | 引导页重跑 `pkg`；校验 `engines.dsh`；重跑安装 |
| ★ 引擎反复失败进安全模式 | 坏插件把引擎搞挂 | 安全模式下改配置 → 恢复正常模式；会话不丢 |
| ★ 手机浏览器能打开 3080 | 绑了 0.0.0.0 | 必须 `--host 127.0.0.1`；CI 静态扫描 |
| ★ 同机网页能发请求 | 未覆盖 Host 头 / 带了 Origin | 按 §4.2 修客户端 |
| ★ 前台 30min 后被杀 | 厂商省电策略 | 电池优化放行 + 最近任务锁定；提示并直达设置 |
| ★ 发热 / 卡顿 | 手机跑重任务 | 接电源或切远程档案；低配机默认推荐远程 |
| ★ 升级 APK 后对话清空 | 签名变更导致卸载重装 | 签名必须固定；先导出 |
| ★ 切换主机后"历史不见了" | 误以为会话跟着账号走 | 正常行为；确认弹窗与顶部执行位置；按 hostId 回原主机查看 |
| ★ 请求 409 `HOST_MISMATCH` | 带旧 hostId 打到新链路 | 清空会话视图，按当前 hostId 重建 |
| ★ 409 `COMMIT_DRIFT` | 某主机 DSH 版本漂移 | 该主机重跑安装引导到 pinned commit |
| **★ 手机上官方 UI 不好用** | 装了第三方窄屏适配插件 / 版本不是 pinned commit | 卸载所有第三方皮肤插件；确认双端 `pinned-commit.txt` = v0.2.2-rc.1；跑 TC-5.20 冒烟 |
| **★ 切档案后界面变了** | 三档案没落到同一个官方 `dsh web` | 检查 SSH `:3081` / Relay 反代目标；应为该 Host 的官方 `dsh web`，不是自托管 UI |
| **★ PC 离线白屏** | 远程档案依赖 PC 在线 | 应显示 Kotlin 原生离线页；未出现即为缺陷（TC-5.19） |
| **★ 升级后窄屏错位** | 上游 rc 版本改动了官方移动端布局 | 不要补 CSS；走 W15 上游兼容回归，单开 ADR 升 `pinned-commit` |
| ★ 插件装了看不见 | 手机不做插件（正常） | 确认 WebView 能打开官方 `dsh web`；无需装任何手机插件 |
| ★ 工具卡不显示 | 超限额 / 清单校验失败 | 看插件详情问题数；≤8KiB/≤32KiB/≤4Hz；连续 5 次违规降级 web |
| ★ iOS 没有本机引擎入口 | 产品降级 | 正常；用 PWA 连 ssh / relay |
| 手机看不到 PC 设备 | 未开允许连接 / client 半边未重启 / Host 未连 Relay | 依次查开关 → `--dump-config` → 重启 → relay 日志 |
| 设置页没有「手机连接」 | client 半边缓存 | 重启一次 DSH |
| 409 `HOST_OFFLINE` | 主机离线 / 锁屏休眠 | 查保持唤醒与 15s 心跳 |
| 消息重复 | `clientMsgId` 未稳定生成 | 检查幂等键；去重窗口 24h |
| 手机刷出 token 碎片 | `assistant/chunk` 未折叠 | TC-1.3 |
| 断网后历史缺一截 | 用了时间戳当游标 | 改连续 `seq` + `sinceSeq` |
| 审批卡住琥珀点不消 | `$events/result` 未回传 | 查审批面板与 ws-frame 透传 |
| 插件卸载后路由仍在 | 注册未交 `ctx.effect` | 修 disposer；TC-5.10 |

## 9. 升级与回滚

### 升级顺序（协议先行）

```
1. PROTOCOL.md / 契约版本 → 2. Relay + CP → 3. 两端插件 → 4. Android APK / PWA
```
`wbsync/1 → 2` 不兼容（hostId 命名空间），Relay 同时兼容两版至少 90 天；新增事件带 `ignorable: true`。

### DSH 上游升级（**双端**）

单独开 ADR，禁止迭代中途 `pnpm update`：

1. 更新 `pinned-commit.txt` 候选值。
2. **PC 与 Termux 两侧**全量契约 + E2E + 混沌。
3. 列出破坏性变更清单（重点 `session/event`、`webServer`、`sessionPersistence`、slots、宿主提交入口）。
4. 灰度验证后才合入；Termux 侧重跑安装引导。

### 回滚

| 组件 | 回滚方式 |
|---|---|
| Relay / CP | 蓝绿切上一版镜像；Postgres 迁移可逆向 |
| PC 插件 | `dsh plugin remove` + 配置备份还原；切回上一 profile |
| **Android APK** | **同签名回退上一版本；严禁换签名** |
| **Termux 引擎** | 安全模式启动（不加载插件）；必要时重置（先导出） |
| 会话数据 | **不需要回滚**：各主机 `~/.dsh` 从未被改写；崩溃走 resume 加 `interrupted`，禁止手工截断 |

## 10. 备份

- **CP Postgres**：每日全量 + WAL；只含元数据。
- **PC `~/.dsh`**：用户自行备份 = 备份该主机全部对话历史。
- **★ 手机 Termux 环境**：当前**无一键完整备份**；引擎重置 / 换签名卸载会清空。需提示用户停机后自行打包 home 目录、工作区、插件与配置；日常重要会话建议导出。
- **禁止**用网盘双向同步任一主机 `~/.dsh`：追加式日志会被撕裂；要走事件流 / resume。
- 令牌摘要、墓碑、主机档案随 CP 备份；恢复后墓碑仍生效。

## 11. 用户须知（写进首次引导页）

1. **手机本地就是一个 DSH 主机**：会话、文件都在手机上；模型仍在云端提供方，需联网并计费。**界面是官方 `dsh web` 的窄屏呈现，我们不提供自定义 UI，也不要装第三方窄屏适配插件。**
2. **切换主机不会带走会话、文件、插件、定时任务**——会话跟着执行位置走，不跟账号走。
3. 同账号只同步设置、Memory、自动化定义与主机列表；**同账号 ≠ 同数据**。
4. 查看历史消息必须连上对应在线主机；离线只能看索引与状态点。
5. PC 需开机、联网、开启允许移动端连接、保持唤醒；锁屏/休眠会断连。
6. Android 需开启前台服务与电池优化放行；**不承诺后台永久存活**；低配机建议用远程档案；发热时切远程。
7. **引擎重置 / 换签名卸载会清空本机数据，请先导出。**
8. iOS 提供 PWA 远程视图，可连电脑发消息、看产物、批审批，**没有本机引擎**。
9. 新开任务是全新会话，不继承上下文；执行中发消息进队列不打断，想停按「停止」。
10. 文件与产物本体始终留在产生它的主机，云端只流转元数据与临时下载票。
